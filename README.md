# 카드샵 공지 스튜디오

매장 사진과 공지 메모를 넣으면 X, 인스타그램, 네이버 카페, 디시인사이드, 네이버 플레이스용 공지글과 공지 카드 이미지를 만들어 줍니다.

| 채널 | 올리는 방식 |
|---|---|
| X · 인스타그램 | Postiz에 **초안**으로 저장 → Postiz 화면에서 확인 후 게시 |
| 네이버 카페 | 텔레그램에서 **승인 버튼**을 누르면 카페에 게시 |
| 디시인사이드 | 제목·본문 복사 → 글쓰기 화면에서 직접 등록 |
| 네이버 플레이스 | 글 복사 → 스마트플레이스에서 직접 등록 |

> 윈도우 10/11 PC 기준입니다. 모든 키와 기록은 **이 PC에만** 저장됩니다.

---

## 1. 설치 (처음 한 번)

### 1-1. Docker Desktop 설치
X·인스타그램 연동(Postiz)에 필요합니다. 네이버·디시만 쓸 거라면 건너뛰어도 됩니다.

1. https://www.docker.com/products/docker-desktop 에서 **Download for Windows**를 받습니다.
   대부분의 PC는 **AMD64**입니다. (설정 → 시스템 → 정보 → 시스템 종류에서 확인)
2. 설치 화면에서 **Use WSL 2** 가 체크된 상태로 설치하고, 안내대로 재부팅합니다.
3. Docker Desktop을 한 번 실행해 약관에 동의합니다. 로그인은 건너뛰어도 됩니다.

### 1-2. 프로그램 받기
1. 받은 압축 파일을 원하는 폴더(예: `문서\공지스튜디오`)에 **압축 풀기** 합니다.
2. 폴더 안의 **`install.bat`** 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 처음에는 프로그램과 Postiz를 내려받느라 **10~20분** 걸릴 수 있습니다.
4. 끝나면 바탕화면에 **「카드샵 공지 스튜디오」** 바로가기가 생깁니다.

---

## 2. 실행과 종료

- **실행:** 바탕화면 바로가기(또는 `start.bat`)를 더블클릭하면 브라우저에 `http://localhost:8000` 이 열립니다.
  검은 창은 **닫지 말고** 최소화해 두세요. 창을 닫으면 프로그램이 꺼집니다.
- **종료:** 검은 창을 닫습니다. Postiz까지 꺼서 메모리를 확보하려면 `stop.bat` 을 실행하세요.

---

## 3. 처음 설정

브라우저 화면 위쪽의 **설정** 탭에서 입력합니다. 입력한 키는 이 PC의 `.env` 파일에만 저장됩니다.

### 3-1. 매장 이름 · Gemini 키 (필수)
1. **매장 이름**: 공지 카드 하단에 표시됩니다.
2. **Gemini API 키**: https://aistudio.google.com → **API 키 만들기** → 복사해 붙여넣기
3. **저장** → 「글 생성」 칸의 **연결 확인**

> 비용: 공지 1건에 약 100~250원 수준입니다(모델·단가에 따라 다름). AI Studio의 **지출 → 월 지출 한도**를 걸어 두면 안전합니다.
> 결제를 연결하지 않은 무료 키도 쓸 수 있지만, 입력 내용이 Google 제품 개선에 쓰일 수 있습니다.

### 3-2. 텔레그램 (네이버 카페 승인용)
1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 이름과 `..._bot` 으로 끝나는 아이디를 정하면 **토큰**이 나옵니다.
2. 만든 봇에게 아무 메시지나 한 번 보냅니다. (안 보내면 봇이 메시지를 못 보냅니다)
3. `@userinfobot` 에게 말을 걸면 나오는 **Id 숫자**가 chat ID입니다.
4. 설정 탭에 토큰과 chat ID를 넣고 **저장 → 연결 확인**. 텔레그램에 확인 메시지가 오면 성공입니다.

### 3-3. 네이버 카페
1. https://developers.naver.com → **Application → 애플리케이션 등록**
   - 사용 API: **네이버 로그인**과 **카페** (카페의 **글쓰기** 권한 체크)
   - 네이버 로그인 제공 정보: 필수 항목은 최소로 (회원이름만 남겨도 됩니다)
   - 환경: **PC 웹** / 서비스 URL `http://localhost:8000` / **Callback URL `http://localhost:8000/naver/callback`**
2. 발급된 **Client ID / Client Secret** 을 설정 탭에 넣고 **저장**
3. **네이버 로그인** 버튼 → 글을 올릴 네이버 계정으로 로그인·동의 → "연결 완료" 화면이 나오면 성공
4. **카페 ID / 게시판 ID**: 카페에서 글을 올릴 게시판을 열고 주소의 `clubid=숫자`, `menuid=숫자` 를 넣습니다.
   - 로그인한 계정이 그 카페 회원이고, 그 게시판에 글쓰기 권한이 있어야 합니다.

> 401 / `errorCode 024` 오류가 나면 카페 **글쓰기** 권한이 빠진 것입니다. 개발자센터에서 권한을 확인하고, 네이버 내정보 → 연결된 서비스에서 앱 연결을 해제한 뒤 다시 **네이버 로그인**을 누르세요.

### 3-4. X (트위터)
1. https://console.x.com 에서 개발자 계정과 앱을 만듭니다.
2. 앱의 **User authentication settings**
   - App permissions: **Read and write**
   - Type of App: **Native App**
   - Callback URI: `http://localhost:4007/integrations/social/x`
3. **Keys and tokens → OAuth 1.0a → Consumer Key → Regenerate** 로 나온 **API Key / API Key Secret** 을 설정 탭에 넣고 저장
4. **Postiz 다시 시작** 버튼을 누르고 1~2분 기다립니다.
5. **Postiz 열기**(http://localhost:4007) → 계정 만들기 → **채널 추가 → X** 로그인·승인
6. Postiz **Settings → Agents / Dev** 의 **API 키**를 복사해 설정 탭 「Postiz API 키」에 넣고 저장 → **연결 확인**에 `x` 가 보이면 성공

### 3-5. 인스타그램 (선택)
인스타 계정이 **프로페셔널(비즈니스/크리에이터)** 이어야 합니다.
1. https://developers.facebook.com/apps/creation → 유형 **기타(Other)** 로 앱 생성
2. **Instagram** 제품 추가 → **Instagram 비즈니스 로그인** 설정
   - Redirect URI: `http://localhost:4007/integrations/social/instagram-standalone`
3. 같은 화면의 **Instagram App ID / App Secret** 을 설정 탭에 넣고 저장 → **Postiz 다시 시작**
4. 앱 역할 → **Instagram 테스터**에 본인 인스타 계정 추가 → https://www.instagram.com/accounts/manage_access/ 에서 초대 수락
5. Postiz → 채널 추가 → **Instagram (Standalone)**

> 이미지가 이 PC 안에만 있어서, 인스타그램 **실제 게시**는 이미지를 외부에서 볼 수 있어야 할 수 있습니다(추가 설정 필요).

### 3-6. 디시인사이드
설정 탭의 **디시 기본 갤러리**에 갤러리 ID(예: `boardgame`)를 넣습니다. 마이너·미니 갤러리는 **갤러리 주소 전체**를 붙여넣으세요.

---

## 4. 공지 만들기

1. **공지 만들기** 탭 → 사진 선택, 공지 종류 선택, **항목 양식 넣기**로 메모 작성 → 올릴 채널 체크 → **공지 만들기**
2. 채널별 탭에서 글과 카드 이미지를 확인하고 필요하면 고칩니다. (다시 쓰기는 글 생성 비용이 듭니다)
3. 채널별로 올리기
   - **X·인스타**: 승인 → 전송 → Postiz에서 확인 후 게시
   - **네이버 카페**: 승인 → 전송 → 텔레그램의 **게시 승인** 버튼 (5분 안에)
   - **디시**: 글쓰기 열기 → 제목 복사·붙여넣기 → 본문 복사·붙여넣기 → 사진 첨부 → 등록

**글쓰기 스타일** 탭에 평소 올리던 공지글을 붙여넣으면 그 말투를 따라 씁니다.

---

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| X 전송 시 `All connection attempts failed` | Docker Desktop이 꺼져 있습니다. 켜고 `start.bat` 을 다시 실행하세요. |
| 설정의 연결 확인이 실패 | 키를 다시 붙여넣고 **저장**을 먼저 누른 뒤 확인하세요. |
| 네이버 승인 메시지가 안 옴 | 텔레그램 봇에게 먼저 말을 걸었는지, chat ID가 맞는지 확인하세요. |
| 브라우저가 안 열림 | 직접 `http://localhost:8000` 을 여세요. |
| Docker Desktop이 켜지지 않음 | 윈도우 업데이트 후 관리자 PowerShell에서 `wsl --update` 를 실행하고 재부팅하세요. |

---

## 6. 백업 · 업데이트 · 주의

- **백업할 파일:** `.env`(키), `config\campaigns_history.db`(지난 공지), `config\style_profiles.json`(글쓰기 스타일)
- **업데이트:** 새 버전 압축을 풀고, 위 3개 파일을 새 폴더의 같은 위치로 복사한 뒤 `install.bat` 을 실행합니다.
- **`.env` 파일은 절대 남에게 보내지 마세요.** 모든 키가 들어 있습니다.
- 디시는 자동 게시를 지원하지 않습니다. 각 사이트의 운영 정책을 지켜 주세요.
